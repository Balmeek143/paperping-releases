## What is PaperPing?

PaperPing is a Windows and macOS desktop reminder companion that sends smooth, animated flyers across your desktop when meetings or personal tasks are due. It provides non-intrusive cues designed to keep you focused without breaking your workflow.

- **Non-blocking flights:** Transparent, click-through overlay flights that never steal keyboard or mouse focus.
- **Calendar Integration:** Google Calendar sync to alert you of upcoming meetings ahead of schedule.
- **Personal & Recurring:** Local custom alerts and recurring intervals without external dependencies.
- **Customizable Flyers:** Choose from built-in character planes, animations, or your own GIF flyers.

- **Internet Connection:** Required for Google Calendar synchronization and license validation

---

## Installation Guide

1. Download `PaperPing-Setup.exe` from the latest release or direct link above.
2. Run the installer:
   > *Note:* If Windows SmartScreen displays a warning, click **"More info"** and then select **"Run anyway"**.
3. Follow the on-screen setup prompts. PaperPing will start and settle into your system tray.
4. Open the tray menu or settings window to activate your license key and configure your reminders.
